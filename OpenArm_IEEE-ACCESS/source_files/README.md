# Source files

This folder collects the user-provided hardware and simulation sources relevant to the KALO-H
IEEE Access study.

## Hardware

- `ROMO-B_manual_complete_compressed.pdf`: complete 38-page derivative of the 368.6 MB scan.
- `Livox_Mid-360_quick_start_guide_ko.pdf`: original user-provided Livox guide.
- `OpenArm_drive_commands_jeongmin.pdf`: original user-provided OpenArm command summary.
- `OpenArm_drive_summary_janghyun.pdf`: original user-provided OpenArm operation summary.
- `OpenArm_v1_ClassicCAN_ExoArm_command_manual.pdf`: original user-provided CAN manual.
- `OpenArm_v1_ExoArm_command_poster.png`: original user-provided poster.

## Simulation

- `openarm_test.usd`
- `openarm_test_v2.usd`

The ROMO-B original bytes are not committed because the file is 368,621,615 bytes and exceeds
GitHub's 100 MB single-file limit. Its SHA-256 and local provenance are recorded in
`../references/source_manifest.tsv`. No subscription-only paper PDF is included.
