# ROMO-B 및 Livox Mid-360 통합 스펙시트

- 문서 상태: 사용자 제공 원문 2종을 대조한 비공식 기술 요약
- 작성일: 2026-07-23
- 대상: ROMO-B 4WID-4WIS 모바일 플랫폼과 Livox Mid-360 LiDAR

> 이 문서는 제조사 공식 사양서를 대체하지 않는다. 수치와 절차는 저장소에 보존된
> 원문에서 옮겼다. 원문 충돌은 빈도와 문서 내 일관성을 근거로 적용 기본값을 정하되
> 이상치를 삭제하지 않았고, 누락 항목은 시험 기본값 또는 확인 전 사용 금지로 구분했다.

## 1. 출처와 표기 규칙

### 1.1 원문

- `R1`-`R38`: [ROMO-B 38쪽 전체 압축본](../source_files/hardware/ROMO-B_manual_complete_compressed.pdf)의 PDF 쪽 번호
- `L1`-`L6`: [Livox Mid-360 한국어 퀵 스타트 가이드](../source_files/hardware/Livox_Mid-360_quick_start_guide_ko.pdf)의 PDF 쪽 번호
  - 인쇄된 책자 쪽 번호는 각각 27-32쪽이다.
- ROMO-B 원본 스캔은 368,621,615 byte이고 SHA-256은
  `32e16889cd27fea2489214dd198c9409a42880a8ae6564287f7e676b4fcac9a4`다.
- Livox PDF는 사용자가 제공한 파일과 저장소 파일의 SHA-256이 모두
  `98d086dd5fdb8e82c22dcf901618a16c934ca26d3daad57784841aec00786bfa`로 일치한다.

### 1.2 신뢰도 표기

| 표기 | 의미 |
|---|---|
| 명시 | 원문 표 또는 본문에 직접 적힌 값 |
| 파생 | 원문 명시값으로 계산한 값 |
| 권장 | 통합 및 시험을 위한 공학적 권장사항으로, 제조사 명시가 아님 |
| 기본값 | 반복 빈도와 문서 내 일관성으로 선택해 계산·설정에 즉시 적용하는 값 |
| 시험 기본값 | 원문에 없지만 저에너지 벤치 검증을 시작하기 위해 임시 적용하는 값 |
| 확인 필요 | 실측 또는 제조사 확인 결과로 갱신해야 하는 항목 |
| 확인 전 사용 금지 | 잘못 가정하면 장비 손상이나 제어 상실 위험이 있어 값을 추측하지 않는 항목 |

### 1.3 축거 기본값 판정

- PDF 전체에서 `323 mm` 또는 `0.323 m`는 6회다: `R2` 1회, `R5` 1회,
  `R26` 3회, `R35` 1회.
- `324 mm` 또는 `0.324 m`는 `R3`에 1회만 나온다.
- 따라서 `L = 0.323 m`를 계산, 시뮬레이션 및 초기 설정의 **기본값**으로 적용한다.
- `0.324 m`는 삭제하거나 평균내지 않고 고립된 원문 이상치로 보존한다.
- 실측값이 확보되면 좌·우 축거를 각각 3회 이상 측정하고 측정 불확도를 함께 기록한
  뒤, 재현성 있게 다른 경우에만 하드웨어 보정값으로 교체한다.

### 2.1 전원 통합 필수 조건

ROMO-B 매뉴얼의 배터리 완충 표기값은 27.2 V이고 Mid-360의 허용 입력 상한은
27 V다. 완충 상태에서 0.2 V 초과하므로 다음 조건을 적용한다.

- **Mid-360을 ROMO-B 배터리 또는 배터리 출력 포트에 직접 연결하지 않는다.**
- 출력이 모든 정상·과도 조건에서 9-27 V 안에 머무는 정전압 DC-DC 전원부를 사용한다.
- LiDAR 분기에는 정격에 맞는 퓨즈, 역극성 방지, 과전압 및 서지 보호를 둔다.
- ROMO-B 충전기는 29.2 V를 출력하므로 충전 중 LiDAR 전원 경로가 배터리/충전
  버스에 연결되지 않게 한다.
- 최종 배선 전에는 플랫폼 전원 출력 포트의 실제 전압, 극성, 접지 구조와 허용
  전류를 측정한다. ROMO-B 매뉴얼에는 해당 출력 포트의 상세 전기 사양이 없다.

근거: ROMO-B `R4`, `R10`, `R24-R25`; Livox `L3`, `L6`.

- Ackermann 계산 초기값은 `L = 0.323 m`, `W = 0.390 m`로 둔다.

- `529 mm`는 일반 사양과 외형도상의 윤거이고, `390 mm`는 매뉴얼이 조향 계산에

## 4. ROMO-B 조향 및 속도 제한

### 4.1 HLV 명령 제한

| 모드 | `STEER_MODE` | 등가 조향 명령 | 비고 | 근거 |
|---|---:|---:|---|---|
| 2WIS | `0x00` | -22 to +22 deg | 전륜 조향 | R3, R36 |
| 4WIS | `0x01` | -18 to +18 deg | 전후륜 반대 방향 조향 | R3, R36 |
| Pivot | `0x02` | 고정 바퀴각 사용 | `SPEED` 부호로 회전 방향 결정 | R31, R36 |

속도 명령 범위는 모든 모드에서 -1.5 to +1.5 m/s다.

### 4.2 18 deg 등가 조향 예시

| 모드 | FL | FR | RL | RR | 설명 |
|---|---:|---:|---:|---:|---|
| 2WIS | 15.2 deg | 22.0 deg | 0 deg | 0 deg | 바퀴각 크기 예시 |
| 4WIS | 13.1 deg | 28.1 deg | 13.1 deg | 28.1 deg | 후륜은 전륜과 반대 방향 |

근거: `R3`. 좌우 회전 방향에 따라 부호와 안쪽/바깥쪽 바퀴가 대칭으로 바뀐다.

### 4.3 4WIS 수식 주의

`R29-R30`의 일부 치환식은 `R = L/tan(delta)`로 읽히지만, 같은 페이지의 기하 정의와
`R3`의 18 deg 예시를 만족하는 관계는 다음과 같다.

```text
R = (L/2) / tan(delta)
```

따라서 4WIS 구현과 검산에는 위 식을 사용한다. 이는 원문 도식과 숫자를 함께
검산한 해석이며, 최종 제어기는 실차 조향각을 측정해 확인해야 한다.

### 4.4 Pivot

| 바퀴 | 조향각 | CW일 때 바퀴 속도 | CCW일 때 바퀴 속도 |
|---|---:|---:|---:|
| FL | +30 deg | 0 to +1.5 m/s | -1.5 to 0 m/s |
| FR | -30 deg | -1.5 to 0 m/s | 0 to +1.5 m/s |
| RL | -30 deg | 0 to +1.5 m/s | -1.5 to 0 m/s |
| RR | +30 deg | -1.5 to 0 m/s | 0 to +1.5 m/s |

Pivot에서 양의 `SPEED`는 CW, 음의 `SPEED`는 CCW다(`R31`, `R36`).

## 5. ROMO-B RS232 인터페이스

### 5.1 링크 사양

| 항목 | 값 | 근거 |
|---|---|---|
| 물리 인터페이스 | RS232 | R18, R38 |
| Baud rate | 115200 bps | R38 |
| Parity | None | R38 |
| Stop bit | 1 | R38 |
| Data bits | 미기재 | R38 |
| 주기 | 50 ms, 20 Hz | R36, R38 |
| HLV to PCU 2-byte 순서 | Big Endian | R38 |
| PCU to HLV 2-byte 순서 | Little Endian | R38 |
| HLV to PCU 프레임 | 13 byte | R38 |
| PCU to HLV 프레임 | 25 byte | R38 |

`8-N-1`은 원문 명시값이 아니라 5.4의 수신 전용 시험 기본값이다. DB9 핀맵과
straight/null-modem 케이블 여부는 원문으로 확정할 수 없다.

### 5.2 HLV to PCU 명령 프레임

| Offset | 길이 | 필드 | 값/범위 |
|---:|---:|---|---|
| 0 | 1 | `S` | `0x53` |
| 1 | 1 | `T` | `0x54` |
| 2 | 1 | `X` | `0x58` |
| 3 | 1 | `AorM` | `0x00` Manual, `0x01` Auto |
| 4 | 1 | `ESTOP` | `0x00` Off, `0x01` On |
| 5 | 1 | `STEER_MODE` | `0x00` 2WIS, `0x01` 4WIS, `0x02` Pivot |
| 6 | 2 | `SPEED` | -150 to +150, Big Endian |
| 8 | 2 | `STEER` | -300 to +300, Big Endian |
| 10 | 1 | `ALIVE` | 0-255 |
| 11 | 1 | `ETX[0]` | `0x0D` |
| 12 | 1 | `ETX[1]` | `0x0A` |

변환:

```text
SPEED raw = target speed [m/s] x 100
STEER command: 문서상 1 raw = 1 deg
```

프레임의 `STEER` 표기 범위와 별개로 실제 모드 명령 한계는 2WIS ±22 deg,
4WIS ±18 deg다. 개별 바퀴 한계는 ±30 deg다.

예시:

```text
조건: Auto, E-Stop Off, 2WIS, 0.50 m/s, 우조향 10 deg, ALIVE 1
바이트: 53 54 58 01 00 00 00 32 00 0A 01 0D 0A
```

### 5.3 PCU to HLV 피드백 프레임

| Offset | 길이 | 필드 |
|---:|---:|---|
| 0 | 3 | `S`, `T`, `X` = `53 54 58` |
| 3 | 1 | `AorM` |
| 4 | 1 | `ESTOP` |
| 5 | 1 | `STEER_MODE` |
| 6 | 2 | `FL_SPEED` |
| 8 | 2 | `FR_SPEED` |
| 10 | 2 | `RL_SPEED` |
| 12 | 2 | `RR_SPEED` |
| 14 | 2 | `FL_STEER` |
| 16 | 2 | `FR_STEER` |
| 18 | 2 | `RL_STEER` |
| 20 | 2 | `RR_STEER` |
| 22 | 1 | `ALIVE` |
| 23 | 2 | `ETX` = `0D 0A` |

모든 2-byte 수치는 Little Endian이다.

```text
wheel speed [m/s] = raw x 0.01, 표기 오차 ±5%
wheel steering [deg] = raw x 0.1, 표기 오차 ±1 deg
```

### 5.4 프로토콜 시험 기본값과 제한

| 항목 | 시험 기본값 | 벤치 확인 방법 | 확인 전 제한 |
|---|---|---|---|
| Data bits | `8-N-1`, 115200 baud | 송신 없이 20 Hz의 유효한 25-byte 프레임을 10초 이상 연속 수신 | 유효 프레임이 없으면 송신 금지 |
| 음수 2-byte 값 | signed int16 two's complement; 명령은 Big Endian, 피드백은 Little Endian | 바퀴를 띄우고 `-1, 0, +1` 최소 명령의 바이트·회전 방향 대조 | 방향 확인 전 지상 주행 금지 |
| `ALIVE` | `(alive + 1) mod 256` | 속도 0에서 `254, 255, 0, 1` 전이를 통과하며 Auto Fail 여부 기록 | wrap 확인 전 무인 운용 금지 |
| CRC/checksum | 문서의 고정 13/25-byte 프레임 외 추가 필드 없음 | 수신 전용 확인 뒤 속도 0 명령으로 응답 확인; 거부 시 공식 시험 프로그램 패킷 대조 | 임의 CRC를 만들어 송신하지 않음 |
| `AorM`, HLV `ESTOP` | 명시적인 `0 -> 1` 전환 후 `1` 유지 | 바퀴를 띄우고 속도 0에서 상태 전이와 피드백 기록 | 상태 전이 확인 전 자동 주행 금지 |
| DB9 핀맵·케이블 | 기본값 없음 | 전원 OFF 연속성, 유휴 전압, 제조사 자료로 TX/RX/GND 및 straight/null-modem 확인 | 추측 배선·무작위 교차 연결 금지 |
| Auto Fail 제동 | 기본값 없음 | 독립 E-Stop 담당자 아래 저속에서 HLV 정지·케이블 단선·`ALIVE` 정지별 실제 운동 기록 | 독립 watchdog과 물리 E-Stop 없이 의존 금지 |

약 0.3초 동안 `ALIVE`가 갱신되지 않으면 Auto Fail 조건이다(`R20`). 그러나 Auto Fail
표는 `E-Stop Off`라고 하고 E-Stop 진입 조건에는 Auto Fail을 포함하므로, 실차 검증
전에는 Auto Fail을 안전 정지 기능으로 간주하지 않는다(`R20-R21`).

## 7. 기계 및 센서 통합 조건

### 7.1 장착

- 수평 360 deg 및 수직 -7 to +52 deg FOV가 플랫폼, OpenArm, 케이블, 적재물에
  가려지지 않는 위치를 선택한다.
- 다른 LiDAR의 레이저가 Mid-360 광학창을 직접 향하지 않게 한다. 원문은 겹치는
  빔이 복구 불가능한 손상을 일으킬 수 있다고 경고한다(`L2`).
- ROMO-B에는 shock absorber가 없으므로 강성이 충분한 브래킷과 적절한 진동
  대책을 사용하고, 장착 후 포인트 클라우드 흔들림과 IMU 노이즈를 측정한다.
- 광학창을 가리거나 하중을 주지 않는다. 센서를 분해하지 않는다.

### 7.2 인터페이스 분리

```text
Livox Mid-360 -- 100BASE-TX Ethernet --> Ubuntu/ROS 2 컴퓨터
Ubuntu/ROS 2 컴퓨터 -- USB-to-RS232 --> ROMO-B PCU
```

LiDAR RJ45와 ROMO-B RS232는 전기적·프로토콜적으로 다른 인터페이스다. RJ45에
PoE를 인가하지 않고, ROMO-B Serial Port에 TTL UART를 직접 연결하지 않는다.

### 7.3 통합 전 확인할 항목

- ROMO-B 배터리 전원 출력 포트의 전압 범위, 전류 정격, 핀맵 및 접지
- RS232 DB9 핀맵과 straight/null-modem 케이블 종류
- USB-to-RS232 변환기의 절연 필요성
- LiDAR DC-DC 전원부의 기동/정지 과도전압
- `base_link`에서 Mid-360 `O-XYZ`까지의 6-DoF 외부 파라미터
- 장착 브래킷의 고유진동수와 OpenArm 동작 시 가림 영역
- 여러 센서 사용 시 시간 동기화와 고정 IP 충돌

## 8. 원문 충돌 및 한계 요약

1. ROMO-B 축거는 323 mm가 6회, `R3`의 324 mm가 1회다. 전자를 기본값으로 적용한다.
2. 조향 계산에는 일반 윤거 529 mm가 아니라 조향축 간 거리 390 mm를 사용한다.
3. 4WIS 일부 치환식은 예시값과 충돌하므로 `R = (L/2)/tan(delta)`로 검산한다.
4. RS232 Data bits, 핀맵, 케이블 결선은 원문에 없다.
5. 음수 표현, `ALIVE` wrap, Auto/ESTOP 상승 에지 조건은 실차 확인이 필요하다.
6. Auto Fail 시 표의 `E-Stop Off`와 E-Stop 조건 설명이 충돌한다.
7. ROMO-B 완충 전압 27.2 V는 Mid-360 입력 상한 27 V보다 높다.
8. Livox Viewer 2의 지원 OS 표기는 Windows 10 64-bit와 Ubuntu 18.04 64-bit로,
   최신 환경 지원 여부를 이 문서만으로 판단할 수 없다.
9. ROMO-B의 100 kg payload는 하중 위치, 무게중심, 동적 감속 조건이 명시되지
   않았으므로 OpenArm 자세와 함께 안정성 한계로 바로 사용할 수 없다.

### 8.1 나머지 확인 필요 항목의 처리 결정

| 항목 | 현재 결정 | 확정 방법과 완료 조건 |
|---|---|---|
| RS232 Data bits·signed 값·`ALIVE`·상태 에지 | 5.4의 시험 기본값만 벤치에서 사용 | 바퀴를 띄운 상태에서 지정 시험을 통과하고 원시 바이트와 상태 로그 보존 |
| 4WIS 충돌 치환식 | `R = (L/2)/tan(delta)`, `L=0.323 m` 사용 | 원문 예시를 재현한 뒤 저속 외부 궤적과 조향 피드백으로 검증 |
| DB9 핀맵·straight/null-modem | 확인 전 사용 금지 | 전원 OFF 연속성·유휴 전압·제조사 자료가 같은 TX/RX/GND 결선을 지시 |
| USB-RS232 절연 | 접지 구조 확인 전 절연형 변환기 사용 | PC와 플랫폼 간 접지 전위차 및 누설·접지 경로 측정 후 결정 |

| Mid-360 전원 | 보호된 독립 정전압 DC-DC 사용 | 최저·최고 배터리와 부하 과도에서 센서 단자 9-27 V 유지 |
| PCU 피드백의 의미 | 실제 센서 ground truth로 사용하지 않음 | 외부 엔코더/모션캡처와 정지·정속·가감속 데이터를 동기 비교 |
| 바퀴·조향축 기하 | `L=0.323 m`, `W=0.390 m`를 초기값으로 사용 | 좌·우/앞·뒤를 3회 이상 실측하고 평균·편차·측정 불확도 기록 |
