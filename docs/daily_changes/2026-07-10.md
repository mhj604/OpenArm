# 2026-07-10 변경 기록

## 1. 이동 중 조기 release 방지 강화

`hold_until_basket_v12`의 `model_625.pt`를 GUI로 확인했다.

관찰:

- 큐브를 집고 들어올린다.
- 이전보다 더 많이 basket 방향으로 이동한다.
- 하지만 basket에 도착하기 전에 그리퍼를 열어 큐브를 떨어뜨린다.
- 실제 동작은 안정적인 place가 아니라, 이동 중 release/drop에 가깝다.

판단:

- `GOAL_RELEASE_XY_THRESHOLD=0.14`도 실제 동작에서는 여전히 넓다.
- `gripper_open_far_from_goal_xy` 벌점이 `MIN_LIFT_HEIGHT_W` 이상에서만 켜져, 낮게 든 상태에서 이동 중 열기를 충분히 막지 못했다.
- release 보상은 너무 일찍 켜지고, 목표점 밖에서 닫고 유지하는 보상은 늦게 켜졌다.

수정:

- release 허용 범위를 더 좁혔다.
  - `GOAL_RELEASE_THRESHOLD: 0.16 -> 0.11`
  - `GOAL_RELEASE_XY_THRESHOLD: 0.14 -> 0.09`
  - `GOAL_XY_BONUS_TIGHT_THRESHOLD: 0.12 -> 0.10`
- 목표점 밖에서 열기 벌점은 더 일찍 켜지도록 했다.
  - `gripper_open_far_from_goal_xy.minimal_height: MIN_LIFT_HEIGHT_W -> LIFT_PROGRESS_START_HEIGHT_W`
  - weight `-120 -> -220`
- 목표점 밖에서 닫고 운반하는 보상도 더 일찍 켜지도록 했다.
  - `gripper_closed_far_from_goal_xy.minimal_height: MIN_LIFT_HEIGHT_W -> LIFT_PROGRESS_START_HEIGHT_W`
  - weight `38 -> 72`
- 목표점 안에서 열기 보상은 더 늦게 켜지도록 했다.
  - `gripper_open_near_goal.minimal_height: MIN_LIFT_HEIGHT_W -> CARRY_LIFT_HEIGHT_W`
  - `gripper_open_near_goal_xy.minimal_height: MIN_LIFT_HEIGHT_W -> CARRY_LIFT_HEIGHT_W`
- basket 방향 이동 보상을 다시 강화했다.
  - `right_hand_y_transport_after_grasp: 42 -> 56`
  - `object_goal_xy_progress: 34 -> 42`
  - `object_goal_y_tracking_broad: 38 -> 46`
  - `object_goal_y_progress: 58 -> 72`
  - `object_goal_y_shortfall: -46 -> -58`

의도:

- basket에 도착하기 전까지는 그리퍼를 열지 않게 한다.
- 물체를 낮게 들고 이동하는 중에도 조기 release 벌점이 작동하게 한다.
- 충분히 높게 들고 basket XY 안에 들어간 뒤에만 release가 유리하도록 만든다.
