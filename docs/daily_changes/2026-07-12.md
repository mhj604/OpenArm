# 2026-07-12 OpenArm 변경 기록

## v28 actor-mean 파지 격차 수정

v27은 5000 iteration을 완료했고 stochastic TensorBoard 지표에서는 파지 약 `97%`, 성공 최고
약 `83%`가 나왔다. 그러나 `model_3650.pt`를 동일한 Stage-Play 조건에서 128개 환경의 actor
mean으로 각 환경 첫 완전 episode만 평가하면 다음과 같았다.

```text
grasp ready       109/128 = 85.16%
candidate         105/128 = 82.03%
verified grasp    104/128 = 81.25%
lift/transport    100/128 = 78.13%
success latch       91/128 = 71.09%
failed latch         7/128 =  5.47%
timeout latch       31/128 = 24.22%
```

위 항목은 단계별/종료 event latch라 상호 배타적인 outcome 표가 아니다. 같은 마지막 control step에
failed와 timeout 조건이 함께 참이 될 수 있으므로 합계가 128을 넘을 수 있다.

TensorBoard grasp는 거짓 물체 이동이 아니었다. strict tracker가 cube/TCP 동반 상승과 coupling,
실제 transport를 검증했으므로 sampled rollout에서는 실제로 성공했다. 문제는 학습 actor가 평균
`.1429`의 Gaussian std를 유지해 관절 target에 축당 약 `.065-.074rad`의 무작위 보정을 받았고,
GUI는 잡음 없는 actor mean을 사용했다는 점이다. 또한 TensorBoard episode 값은 서로 다른 시점에
끝난 reset batch를 평균하므로 빠른 episode와 느린 timeout을 동일한 배포 성공률로 해석할 수 없다.

단계별 손실은 ready 이전 `19/128`, ready 이후 verified grasp까지 `5/128`이었다. 따라서 bilateral
contact, coupling, hold gate를 느슨하게 만드는 대신 actor mean이 정렬 중심에 안정적으로 들어가게
수정한다.

### 장면과 초기 자세

- 로봇 기준 오른쪽은 `-Y`다. cube nominal Y를 `-.10 -> -.15m`로 이동했다.
- 기존 랜덤 배치 최악 조건의 cube 면과 basket 외벽 여유는 약 `9.6mm`였다. 변경 후 약
  `59.6mm`가 되어 손가락 접근 공간을 확보한다.
- cube만 옮기면 기존 TCP-local alignment gate를 벗어나므로 ready joint 7개를 함께 보정했다.
  새 FK/IK 해는 TCP 위치만 world `-Y 50mm` 이동하고 기존 TCP orientation과 cube-local grasp
  offset을 보존한다. 모든 관절은 limit 안에 있다.
- object reset randomization `x/y +/-15mm`, yaw `+/-0.35rad`는 그대로 유지한다.

### 보상, 관측, PPO

- episode의 새 alignment 최고점에만 총 `+30`을 지급하던 `approach_progress`를 제거했다.
- actor가 arm을 소유하고 grasp attempt 전인 동안 현재 `grasp_alignment_quality * 5`와 normalized
  consecutive alignment dwell `* 1`을 매초 보상한다. 최대 `+6/s`는 기존 pregrasp delay
  `-7.5/s`와 elapsed `-0.5/s`보다 작아 centered hover도 계속 손해이며 3-step close를 빨리
  완료해야 유리하다.
- sampled raw action이 들어가고 close/retry/assist 때 실제 applied target과도 달랐던 `last_action`
  8차원을 제거했다. 이에 따라 부분관측 항목이 된 미세한 action-rate penalty도 Stage reward에서
  제거했다. joint velocity penalty와 assist/handoff joint-step 제한은 유지한다.
  observation/action/reward 계약은 `75/8/20`이다.
- Stage PPO의 학습 가능한 `init_noise_std .15 -> .05`, `entropy_coef 1e-4 -> 0`으로 변경했다.
  `.05`는 고정값이 아니므로 학습 중 learned std와 sampled/mean 차이를 계속 기록한다. v26의 `.05`
  붕괴 원인이었던 retry penalty, 최대 시도 failure, negative approach ratchet은 v27에서 이미
  제거됐고, v28은 절대 centered reward로 탐색 신호를 보완한다.
- 3-step alignment dwell, bilateral stopped-finger contact, 실제 object/TCP `12/10mm` 동반 상승,
  `12mm` coupling error, actor-owned lift, hold/transport/PlaceAssist/release/success 조건은 유지한다.

### 검증

- `compileall`, AST parse, `git diff --check`를 통과했다.
- 8 env, 1 iteration headless runtime smoke에서 observation `75`, action `8`, reward `20`, 초기
  Gaussian action std `.05`가 확인됐고 manager/physics가 정상 종료됐다. smoke 로그는 제거했다.
- checkpoint 채택에는 sampled TensorBoard 비율을 사용하지 않는다. 128-env actor-mean에서 각
  환경의 첫 완전 episode만 세고 `lift_completed`, `validated_transport`, success와 최악 reset
  pose를 평가한 뒤 1-env GUI를 확인한다. v28의 개선 여부는 아직 학습 전이라 미확정이다.

최종 checkpoint 채택 조건:

```text
actor-mean, observation corruption off, first complete episode only
seeds 42/43/44/45 x 128 env = 512 episodes
overall lift_completed and validated_transport >= 90%, success >= 80%, timeout <= 15%
each seed lift/transport >= 85%
fixed reset-Y bins [-.165,-.1575), [-.1575,-.150), [-.150,-.1425), [-.1425,-.135]m
각 fixed Y bin n >= 100, lift/transport >= 85%
Stage-Play `--seed=42` 연속 10 episode에서 실제 cube lift/transport >= 9/10, empty transport = 0
learned action std와 동일 조건 sampled/mean 격차도 함께 보고; TensorBoard 값으로 대체 금지
```

신규 학습은 반드시 fresh로 한 줄 실행한다.

```bash
python scripts/rsl_rl/train.py --task=Isaac-PickPlace-OpenArm-TestUSD-Bi-Stage-v0 --num_envs=5120 --device=cuda --max_iterations=5000 --headless --run_name=fresh_clearance_mean_grasp_v28
```

`--resume`, `--load_run`, `--checkpoint`, bootstrap은 추가하지 않는다.
