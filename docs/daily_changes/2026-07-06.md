# 2026-07-06 변경 기록

## 목적

OpenArm 양팔 집기·놓기 실험을 위해 `openarm_test` USD 장면의 물리 배치를 조정했다.

## 환경/USD 변경

- 로봇과 높은 작업 테이블을 분리했다.
- 로봇은 낮은 받침 테이블 위에 두었다.
- 높은 작업 테이블은 로봇 앞쪽으로 배치했다.
- 바스켓은 높은 작업 테이블 위에 유지했다.
- 바스켓 옆에 물체를 놓을 공간을 확보했다.
- 높은 작업 테이블을 가로로 넓혀 바스켓 영역과 물체 배치 영역을 나눌 수 있게 했다.

## 유지한 것

- 로봇 색상은 수정하지 않았다.
- 로봇 자산 자체는 바꾸지 않았다.
- GitHub 저장소에서는 최종 USD를 `assets/openarm_test.usd`라는 기본 이름으로 관리한다.
- 로컬 작업명 `openarm_test_v2.usd`는 GitHub 파일명으로 사용하지 않는다.
