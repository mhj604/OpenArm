# 2026-07-20

## V48 종료와 V49 근접 정렬 감속

- v48 학습은 3425회에서 종료했다. GUI 기준 후보 `model_3000.pt`의 파지·들기·운반은 약
  `96.99/96.87/96.82%`, 성공은 약 `56.39%`였다. 사용자는 파지, 안전 상승, 수평 운반과
  바스켓 충돌 회피는 양호하며 마지막 하강만 지나치게 오래 걸린다고 확인했다.
- 12단계 하강 보간은 하강 시작당 평균 `11.80/12 control`까지 진행됐다. 반면 3cm 하강 구역에서
  sticky 중앙 정렬을 기다린 시간은 약 `77.64 control`이었다. 추종 대기는 약 `4.71`, 안정성
  대기는 약 `6.99 control`이므로 보간 길이나 Z 이득보다 중앙 정렬 전 수평 속도가 주된 후보였다.
- 기존 정지 곡선은 목표 3cm에서 약 `0.123m/s`까지 허용한다. 실제 명목 수평 상한
  `0.075m/s`보다 높아 중앙 정렬 속도 기준 `0.05m/s`를 만족시키기 위한 선행 감속이 없었다.
- v49는 목표 4.5cm 안에서 진입 블렌드가 만든 수평 목표 속도를 `0.045m/s`로 제한한다. 그 뒤에
  기존 정지 곡선, 가속도·저크 제한, 데카르트 안전 투영, DLS, 목표 선행량과 관절 한계를 그대로
  적용한다. 4.5cm부터 3cm까지의 15mm 구간에서 명령 속도를 낮추고 3회 중앙 정렬 확인을 먼저
  끝내는 것이 목적이다.
- 바스켓 안쪽 경계와 목표를 다시 계산하면 3cm 영역 전체에서도 가장 가까운 벽까지 약 81mm가
  남는다. 다만 최종 큐브 바닥은 바스켓 벽 상단보다 약 0.5mm만 높으므로, 중앙 정렬 전에 하강
  목표를 앞당기는 초기안은 폐기했다. 기존 candidate freeze, 12단계 보간, 놓기 높이 `.670m`,
  높이 허용오차 위 `2mm`·아래 `3mm`, 놓기 속도 `.06m/s`를 모두 유지한다.
- 다음 학습에서 원인을 직접 확인하도록 하강 시작 진척도와 중앙 정렬 전 속도 초과 누계를
  `task_post_center_descent_start_progress`,
  `task_post_center_descent_precenter_speed_pause_steps`로 추가했다. 새 속도 누계는 3cm 안에 있고
  아직 sticky 중앙 정렬 전이며 실제 물체 XY 속도가 `0.05m/s`를 넘은 경우만 센다.
- 웹 ChatGPT Pro의 같은 대화에서 1차 검토, 반론 검토, 물리 형상을 반영한 최종 종합 검토를
  진행했다. 하강 잠금을 없애는 안은 반론 단계에서 폐기했고, 진입 블렌드 뒤·정지 곡선과 저크
  제한 앞에서 수평 속도만 제한하는 최종안을 채택했다.
- 전체 회귀 테스트 `154개`, Python 컴파일과 `git diff --check`를 통과했다. Isaac Sim의
  headless 런타임에서 Stage 설정값 `.045/.045/.0025` 생성도 확인했다. 학습과 물리 환경
  롤아웃은 새로 실행하지 않았다.

처음부터 실행하는 명령:

```bash
python scripts/rsl_rl/train.py --task=Isaac-PickPlace-OpenArm-TestUSD-Bi-Stage-v0 --num_envs=5120 --headless --device=cuda --max_iterations=5000 --run_name=fresh_center_brake_descent_v49
```

첫 비교는 2500회와 3000회에서 한다. 최근 50회 파지·들기·운반은 v48 3000회보다 `1%p` 넘게
떨어지지 않아야 한다. 중앙 정렬 전 속도 초과와 전체 중앙 정렬 대기가 함께 줄고,
`phase_assist_to_center_steps + phase_center_to_release_steps` 합계가 늘지 않아야 원인이 맞다.
추종·안정성 대기로 병목이 옮겨가거나 하강 시작 진척도가 1에 가까워지면 채택하지 않는다. 성공은
최소 `55%`를 유지하고 GUI 20회에서 바스켓 접촉, 미끄러짐과 놓기 높이·속도 악화가 없어야 한다.
v48의 3050회 이후 행동자 소유 저고도 붕괴는 이번 근접 감속과 별도 문제로 판단한다.
