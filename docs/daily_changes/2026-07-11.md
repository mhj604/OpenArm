# 2026-07-11

## v25 결정론적 파지와 실제 운반 검증

v24 `model_1125.pt`는 학습 로그에서 성공률이 약 `73.75%`였지만, GUI에서 20회 연속 큐브를
집지 못했다. 팔은 목표점으로 잘 이동했다.

확인된 원인:

- RSL-RL 학습 rollout은 Gaussian sample action을 사용하고 GUI play는 actor mean만 사용한다.
- model 1125의 action std는 평균 `0.2947`, gripper std는 `0.2942`였다. Gripper close threshold는
  `-0.15`인데 마지막 gripper bias는 `-0.0839`라, 학습 중에는 noise가 gripper를 닫고 GUI에서는
  mean이 dead-band에 남아 계속 열릴 수 있었다.
- 기존 grasp/hold proximity는 두 finger score 평균과 `.32/.25` threshold를 사용했다. 한쪽
  finger만 가까워도 gate를 통과할 수 있고, cube 높이가 2 step 올라가면 grasp가 영구 latch됐다.
- 기존 성공 자체는 손 위치가 아니라 실제 cube의 goal XY/Z/speed를 검사했다. 다만 약한 grasp
  latch 뒤 controller가 cube를 밀거나 튕겨 넣은 episode도 pick-place로 집계될 수 있었다.

v25 수정:

- Gripper는 actor sample 임계값에 의존하지 않는다. Bilateral grasp-ready이면 자동 close하고,
  검증된 lift/transport/place/release-ready 뒤에만 자동 open한다. Raw gripper action은 phase 정렬
  보조 신호만 유지하고 penalty를 `-4 -> -1`로 낮췄다.
- Grasp-ready/hold는 두 finger proximity의 최솟값을 사용한다. 빈손 완전 닫힘도 grasp 후보에서
  제외한다.
- Grasp는 cube와 TCP가 각각 `10/8mm` 이상 함께 상승하고, TCP local object offset 오차
  `<=12mm`, object와 TCP object-point 상대속도 `<=0.15m/s`를 5 step 연속 만족해야 한다.
- TCP 속도는 link-origin linear/angular velocity와 `omega x r`을 사용한다. 따라서 정상적인
  wrist rotation을 slip으로 오판하지 않는다. 불안정한 후보는 다음 안정 구간에서 기준점을 다시
  잡을 수 있다.
- Hold는 grasp 시점 TCP-local offset 오차 `<=25mm`, 상대속도 `<=0.20m/s`를 계속 요구한다.
  Lift는 높이 `0.73m`에서 3 step, transport는 verified hold 상태의 실제 cube XY 이동 `>=5cm`를
  3 step 확인한다.
- Place assist, basket, release, success는 verified transport 전에는 시작할 수 없다. Success는
  grasp/lift/transport/basket/center/release 이력과 실제 cube settle pose/speed를 모두 요구한다.
- v24의 arm scale, transport/carry reward, goal, full-6D PlaceAssist gain과 motion limit는 유지했다.
- Stage PPO는 `noise 0.30 -> 0.15`, `entropy 1e-4 -> 0`, `gamma 0.98 -> 0.995`로 변경했다.
  16초 task의 최종 보상이 초기 파지 행동까지 전달되고 sampled rollout과 mean policy의 차이가
  줄어든다. Observation/action/reward 계약은 `74/8/19`로 유지된다.

검증:

- `py_compile` 및 `git diff --check` 통과.
- 8 env, 1 iteration runtime smoke에서 Stage manager, 74 observations, 8 actions, 19 rewards,
  auto gripper, TCP link velocity API가 정상 초기화됐다.
- Smoke에서 mean action noise std `0.15`, false grasp/assist/success는 모두 0이었다.
- 기존 model 1125를 새 gate로 960 frame 재생했을 때도 실제 cube transport는 없었다. 이전
  stochastic 성공률을 재사용하지 않고 fresh policy로 학습해야 한다.

밤샘 신규 학습 명령:

```bash
python scripts/rsl_rl/train.py --task Isaac-PickPlace-OpenArm-TestUSD-Bi-Stage-v0 --num_envs 5120 --device cuda --max_iterations 5000 --headless --run_name fresh_verified_grasp_mean_v25
```

`--resume`, `--load_run`, `--checkpoint`, bootstrap은 사용하지 않는다. 5120 env의 기존 측정값
`4.27s/iteration` 기준 약 5.9시간이며 checkpoint는 25 iteration마다 저장된다.
