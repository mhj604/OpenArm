- 공식 OpenArm 물리 USD의 `enabledSelfCollisions=false`를 그대로 상속하던 경로를 제거했다. 공용
  USD 스포너가 환경 복제 전에 `openarm_bimanual/root_joint`의 루트 레이어에 자체 충돌 `true`를

- 자체 충돌 경로를 호출자 설정에서 제거하고 로봇 `prim_path`·articulation root와 함께 쓰는 단일
  OpenArm 상수로 묶었다. 시작 이벤트는 `spawn=None`과 로봇 바인딩을 확인한 뒤 복제된 모든 환경의
  articulation 값을 읽는다. 하나라도 누락되거나 `false`이면 학습을 시작하지 않는다.

  기본값보다 작았던 `2**23` 대신 `2**25`를 사용한다. patch `2**23`은 사전 측정용 상한 후보이며,
  검증하지 않은 7040개 초과 환경 수는 시작 단계에서 거부한다.
- 현재 실행 중인 `2026-07-16_14-02-36_fresh_authority_primary_descent_v40_e7040`은 장면 생성 뒤
  코드를 수정했으므로 계속 자체 충돌이 꺼진 상태다. 실행 중인 프로세스에는 변경을 적용하거나
  종료 신호를 보내지 않았다.
- 다음 자체 충돌 학습은 기존 체크포인트에서 재개하지 않는다. 먼저 1~16개 환경에서 내부 접촉과

  대규모 환경 수를 정한다. `Patch buffer overflow`, aggregate/found-lost 용량 부족,
  `simulation will miss interactions`가 한 번이라도 나오면 해당 실행의 학습 데이터는 사용하지 않는다.

정적·단위 테스트 `95개`, Python 컴파일과 `git diff --check`를 통과했다. PXR 인메모리 stage에서도

  불리하게 하고, 파지 시점의 0에서 다시 0으로 돌아오는 실패 왕복의 보상 악용을 막았다. 들기
  완료 시에는 potential을 닫지 않고 마지막 상승량을 최대 `+30`의 일회성 완료 보너스로 지급한다.
- 미완료 시간 초과의 파지 뒤 배수만 `2.0 -> 1.0`으로 낮췄다. 행동자가 파지 직후 큐브를
  떨어뜨리면 준비·후보·확정 보상 `+73`을 반복해서 받을 수 있으므로 실패 배수는 `2.0`, 비용은
  `-110`으로 유지했다. 웹 검토안의 두 배수 완화는 이 조기 종료 경로 때문에 일부만 채택했다.
- 전역 자체 충돌은 계속 켠다. 과거 성공 자세와 간격이 충돌하는 좌우 `link5 -> link7` 두 쌍만
  루트 레이어에서 필터링한다. 모든 복제 환경에서 자체 충돌 속성, 양쪽 rigid body, 정확히 하나인
  target 집합과 추가 필터 부재를 시작 전에 확인한다.
- 물체, TCP, 둘 중 작은 결합 상승 진행률을 TensorBoard에 추가했다. 운반·보조 제어·놓기·PPO와
  도메인 무작위화 상태는 변경하지 않았다.
- 회귀 테스트 `108개`, Python 컴파일, `git diff --check`를 통과했다. Headless Isaac의 메모리
  USD stage에서도 두 필터가 실제 `FilteredPairsAPI` 관계로 기록되고 env 0에서 env 1로 복제할 때
  대상 경로가 env 1로 재매핑되며 시작 계약을 통과하는 것을 확인했다. 학습과 물리 스텝은 실행하지
  않아 실제 접촉 억제는 다음 소규모 실행에서 확인한다.

처음부터 학습하는 한 줄 명령:

```bash
python scripts/rsl_rl/train.py --task=Isaac-PickPlace-OpenArm-TestUSD-Bi-Stage-v0 --num_envs=5120 --device=cuda --max_iterations=5000 --headless --run_name=fresh_verified_coupled_lift_v42
```

300회 전에 첫 파지, 500회에 최근 50회 파지 `>=50%`와 평균 결합 상승 진행률 `>=0.02`의 증가 추세,
800회에 첫 들기와 평균 높이 `>=.68m`, 1000회에 들기 `>=70%`, 운반 `>=65%`를 확인한다.
1000회에도 들기 `<1%`·시간 초과 `>99%`면 더 돌리지 않는다.
