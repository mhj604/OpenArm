## 3. PPO 안정화

초기 학습 중 `value_function loss: inf`와 `normal expects all elements of std >= 0.0` 오류가 발생했다.

이를 막기 위해 PPO 설정을 조정했다.

- `empirical_normalization = True`
- `noise_std_type = "log"`
- `learning_rate = 3e-5`
- `schedule = "fixed"`
- `entropy_coef = 0.001`
- `num_learning_epochs = 4`
- `num_mini_batches = 8`

## 4. 학습 후 발견한 문제

5000 iteration 학습 후 다음 문제가 확인됐다.

- 오른팔이 낮은 경로로 움직이며 테이블에 걸려 물체를 pick하지 못했다.
- 왼팔이 task 목적과 관계없이 뒤나 옆으로 움직였다.

원인 판단:

- 왼팔이 policy action space에 포함되어 있어 정책이 왼팔도 제어할 수 있었다.
- reaching reward가 물체 중심으로 바로 접근하도록 유도해, 오른손이 테이블을 피해 위에서 접근하는 동작을 충분히 만들지 못했다.

## 5. 정책 scope 수정

PAP policy를 오른팔 중심으로 제한했다.

변경 전:

- `arm_action`: 왼팔 7 joint + 오른팔 7 joint
- `gripper_action`: 오른손 gripper
- action dimension: `15`
- observation dimension: `61`

변경 후:

- `arm_action`: 오른팔 7 joint만 제어
- `gripper_action`: 오른손 gripper만 제어
- 왼팔 joint는 action/observation/reward penalty 대상에서 제거
- action dimension: `8`
- observation dimension: `36`

코드에 추가한 상수:

- `RIGHT_ARM_JOINT_NAMES = ["openarm_right_joint.*"]`
- `RIGHT_GRIPPER_JOINT_NAMES = ["openarm_right_finger_joint.*"]`
- `RIGHT_POLICY_JOINT_NAMES = RIGHT_ARM_JOINT_NAMES + RIGHT_GRIPPER_JOINT_NAMES`

정책 호환성:

- 기존 15-action PAP checkpoint는 현재 8-action task와 호환되지 않는다.
- 이 변경 이후에는 새로 학습해야 한다.

## 6. 오른팔 테이블 회피 reward 추가

오른손이 물체 중심으로 바로 들어가는 대신, 먼저 물체 위쪽의 pre-grasp 지점을 보도록 reward를 나누었다.

추가한 상수:

- `PRE_GRASP_OFFSET_W = (0.0, 0.0, 0.09)`
- `GRASP_OFFSET_W = (0.0, 0.0, 0.035)`
- `RIGHT_HAND_MIN_CLEARANCE_W = 0.60`

추가한 MDP 함수:

- `object_body_offset_distance()`
- `body_height_below_minimum()`

새 reward 항목:

- `reaching_pre_grasp`: 오른손이 물체 위 pre-grasp point에 접근
- `reaching_object`: 오른손이 물체 근처 grasp point에 접근
- `right_hand_table_clearance`: 오른손이 낮은 경로로 내려가면 penalty

추가 조정:

- 오른팔 action scale을 `0.5`에서 `0.25`로 줄였다.
- 테이블에 걸린 상태에서 과격하게 밀고 들어가는 움직임을 줄이기 위한 변경이다.
