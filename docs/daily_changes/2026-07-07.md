## 6. 오른팔 전방/상방 접근 reward 추가

오른손이 물체 중심으로 바로 들어가는 대신, 먼저 물체 위쪽의 pre-grasp 지점을 보도록 reward를 나누었다.

추가한 상수:

- `PRE_GRASP_OFFSET_W = (0.0, 0.0, 0.08)`
- `GRASP_OFFSET_W = (0.0, 0.0, 0.025)`
- `RIGHT_HAND_MIN_CLEARANCE_W = 0.62`
- `RIGHT_HAND_BACKWARD_LIMIT_X_B = 0.02`
- `RIGHT_HAND_TARGET_FORWARD_X_B = 0.40`
- `RIGHT_HAND_TARGET_HEIGHT_B = 0.30`
- `RIGHT_READY_JOINT_POS`: 오른손이 물체 위 pre-grasp 근처에서 시작하도록 FK 탐색으로 찾은 오른팔 초기 관절값

추가한 MDP 함수:

- `object_body_offset_distance()`
- `body_position_in_robot_root_frame()`
- `object_body_axis_distance()`
- `body_axis_above_minimum()`
- `body_axis_above_minimum_in_robot_root_frame()`
- `body_axis_below_minimum()`
- `body_axis_below_minimum_in_robot_root_frame()`
- `body_height_below_minimum()`

새 reward 항목:

- `reaching_pre_grasp`: 오른손이 물체 위 pre-grasp point에 접근
- `right_hand_forward_alignment`: 오른손 x 좌표를 물체 x 좌표 쪽으로 유도
- `right_hand_forward_progress`: 오른손이 최소 x=0.25m 이상 전방으로 나가도록 유도
- `right_hand_lift_to_pre_grasp`: 오른손을 pre-grasp 높이까지 올리도록 유도
- `reaching_object`: 오른손이 물체 근처 grasp point에 접근
- `right_hand_table_clearance`: 오른손이 낮은 경로로 내려가면 penalty
- `right_hand_backward_guard`: 오른손이 x 음수 방향, 즉 뒤로 빠지면 penalty

추가 조정:

- 오른팔 action scale을 `1.0`에서 `0.5`로 낮췄다.
- `use_default_offset=True` 상태에서 초기 joint offset 자체를 물체 위 pre-grasp 근처로 바꾸고, 정책은 그 주변에서 더 안정적으로 움직이도록 했다.
- 오른손 위치를 observation에 추가했다.

## 7. 오른팔이 뒤로 움직이는 문제 반영

GUI 확인 중 오른팔이 물체 방향이 아니라 뒤쪽으로 움직이는 현상을 확인했다.

이에 따라 다음을 추가했다.

- 오른손 world x 좌표가 물체 x 좌표에 가까워지도록 `right_hand_forward_alignment` reward를 추가했다.
- 오른손 로봇 기준 x 좌표가 최소 `0.40 m` 이상 전방으로 나가도록 `right_hand_forward_progress` reward를 수정했다.
- 오른손 로봇 기준 x 좌표가 `0.02 m`보다 작아지는 움직임은 `right_hand_backward_guard`로 약하게 벌점 처리했다.
- 오른손 로봇 기준 z 좌표가 `0.43 m` 이상으로 올라가도록 `right_hand_lift_to_pre_grasp` reward를 수정했다.
- `reaching_pre_grasp`의 `std`를 `0.16`에서 `0.50`으로 넓혀 초기 상태에서도 reward gradient가 너무 희박하지 않게 했다.
- 큰 음수 penalty가 value loss를 키우는 문제가 있어 `right_hand_backward_guard` weight를 `-8.0`에서 `-2.0`으로 낮추고, 대신 양수 전진 reward를 강화했다.

원인:

- `right_hand_forward_progress`, `right_hand_lift_to_pre_grasp`, `right_hand_backward_guard`가 world 좌표를 기준으로 계산되고 있었다.
- `num_envs=1024`에서는 env가 격자로 복제되므로, 로봇이 실제로 뒤로 움직이지 않아도 env 배치 위치 때문에 world x가 음수가 되는 환경이 생겼다.
- 이 때문에 정책이 잘못된 큰 후퇴 penalty를 받았다.

수정:

- 전진/상승/후퇴 guard를 로봇 root 기준 좌표로 계산하도록 `body_axis_above_minimum_in_robot_root_frame()`과 `body_axis_below_minimum_in_robot_root_frame()`을 추가했다.
- 오른팔 기본 자세를 `RIGHT_READY_JOINT_POS`로 변경했다. FK 탐색 결과, 오른손이 물체 위 pre-grasp 근처에 오는 후보를 사용했다.
- 오른팔 action scale을 `0.5`로 조정했다. OpenArm 튜토리얼과 같은 크기로 맞추고, ready pose 주변에서 과도한 충돌 동작을 줄이기 위한 설정이다.
