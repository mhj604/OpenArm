## 3. Curriculum 수정

500 이후 policy collapse를 만든 것으로 보이는 큰 action/joint penalty 전환을 늦추고 약하게 바꿨다.

- `action_rate` curriculum
  - `weight: -0.02 -> -0.001`
  - `num_steps: 10000 -> 120000`
- `joint_vel` curriculum
  - `weight: -0.01 -> -0.001`
  - `num_steps: 10000 -> 120000`

현재 5000 iteration 학습은 `num_steps_per_env=24`이므로 총 common step은 약 `120000`이다. 따라서 학습 중반에 갑자기 강한 정지 penalty가 켜지는 문제를 막는다.

## 6. 800 iteration 부근 두 번째 정책 붕괴 원인 확인

`2026-07-08_00-12-14` run을 추가로 확인했다.

- `model_700.pt`도 GUI에서 큐브를 집고 조금 이동한 뒤 멈추는 수준이었다.
- step 754 부근에서 `object_goal_tracking=14.50`, `position_error=0.2587`까지 좋아졌다.

원인 판단:

- `Curriculum/action_rate`, `Curriculum/joint_vel`은 계속 `-0.0001`로 유지됐다. 따라서 이번 붕괴는 curriculum penalty 때문이 아니었다.

- 결론적으로, goal reward scale을 크게 키운 상태에서 fixed learning rate PPO가 critic/value 불안정 구간을 지나며 actor policy를 크게 밀어낸 것으로 판단했다.

## 7. PPO collapse 완화 수정

정책이 좋은 grasp/transport 구간을 지나쳐 무너지는 현상을 줄이기 위해 PPO를 더 보수적으로 바꿨다.

- `save_interval: 100 -> 25`
  - peak checkpoint를 놓치지 않기 위함
- `init_noise_std: 0.45 -> 0.30`
- `clip_param: 0.2 -> 0.1`
- `entropy_coef: 0.0003 -> 0.0001`
- `num_learning_epochs: 4 -> 2`
- `learning_rate: 1.5e-5 -> 8.0e-6`
- `schedule: fixed -> adaptive`
- `desired_kl: None -> 0.006`
- `max_grad_norm: 1.0 -> 0.5`

## 8. Goal reward scale 재조정

value loss 폭발을 줄이기 위해 goal reward scale을 낮췄다. 대신 목표 근처 보상은 더 일찍, 더 부드럽게 들어오도록 바꿨다.

- `object_goal_tracking`
  - `weight: 45.0 -> 28.0`
- `object_goal_tracking_fine_grained`
  - `weight: 25.0 -> 10.0`
- `object_goal_bonus`
  - `threshold: 0.12 -> 0.30`
  - `weight: 60.0 -> 20.0`
  - binary reward에서 smooth basin reward로 변경

의도:

- `position_error`가 0.25~0.30m까지 줄어든 정책을 보존한다.
- 하지만 reward scale이 너무 커져 critic/value loss가 폭발하지 않도록 한다.
- 실제 성공 termination threshold `0.055m`는 그대로 유지한다.

판단:

- 정책이 물체를 끝까지 쥐고 운반하기보다, 물체를 밀거나 놓는 shortcut을 탐색할 수 있었다.

- `_closed_grasp_gate()` 추가

- `object_goal_distance_with_grasp()` 추가
  - 물체가 lift 상태이고 closed grasp gate를 통과할 때만 goal distance reward를 준다.
- 기존 goal 관련 reward를 모두 closed grasp gate에 연결했다.
  - `object_goal_tracking`
  - `object_goal_xy_tracking`
  - `object_goal_height_tracking`
  - `object_goal_tracking_fine_grained`
  - `object_goal_bonus_coarse`

  - `object_goal_bonus_tight`
- `gripper_open_near_goal`, `gripper_closed_near_goal` reward는 제거했다.
  - 현재 단계에서는 release를 학습시키기보다, 먼저 물체를 쥔 채 목표까지 안정적으로 운반하는 정책을 만드는 것이 우선이다.
  - release/place reward는 `object_reached_goal`이 실제로 증가한 뒤 별도 단계로 다시 추가한다.
