- v36·v37의 실패 이력을 다시 확인했다. 바스켓 XY 관측을 숨기는 들기 우선 관측은 v37의 파지를

  제어기를 그대로 유지했다.
- 검증 파지부터 `.730m` 들기 완료 전이까지 큐브와 바스켓 사이의 평면 거리가 줄어든 최대량만
  비용으로 추가했다. 반대 방향과 접선 이동은 제외한다. `10mm`는 허용하고 이후에는 `-300/m`,
  안쪽 진행 `6cm`에서 포화되며 최대 비용은 `-15`다.
- 최고값 방식이라 복귀와 반복으로 비용을 되돌리거나 다시 계산하지 않는다. `just_lifted` 전이는
  포함하고, 그 다음 운반부터는 비용을 완전히 끈다. 실패·놓기·시간 초과가 발생한 주기의 마지막
  위험 이동도 계산한 뒤 상태를 끈다.
- `task_prelift_lateral_displacement_max`와
  `task_prelift_inward_progress_max`, `task_prelift_inward_excursion_charged`,
  `task_prelift_inward_cap_hit`을 TensorBoard에 추가했다.
- 기존 근접 저고도 비용, 파지·상승 보상, PPO, 자체 충돌, 보조 제어, 하강과 놓기 조건은 바꾸지
  않았다.
- 전체 회귀 테스트 `132개`, Python 컴파일과 `git diff --check`를 통과했다. 학습과 GUI는
  실행하지 않았다.
